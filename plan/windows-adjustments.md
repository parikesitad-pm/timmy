Windows tidak menjamin handler SIGTERM menjalankan cleanup saat sinyal dikirim dari proses lain. Lihat [Node signal events](https://github.com/nodejs/node/blob/main/doc/api/process.md#signal-events). Batas `.cmd`/`.bat` dijelaskan pada [Node child_process](https://nodejs.org/api/child_process.html#spawning-bat-and-cmd-files-on-windows). Usulan control channel adalah keputusan desain dari temuan ini, bukan API yang sudah tersedia di Timmy.

## P2: voice, CI, distribusi

- `infra/voice-lifecycle.ts:59`: preflight hanya mengecek `python3 --version`, tanpa memvalidasi >=3.11. Usulan: periksa kandidat Windows (`py -3`, `python`, `python3`), parse versi, periksa `git` dan `uv`, dan berikan diagnosis spesifik. Pastikan Python yang dipakai `uv run` memenuhi versi juga. Audit dependency audio repo voice terpisah sebelum menjanjikan dukungan Windows.
- `domain/memory/embedder.ts:39`: Transformers/ONNX dimuat lazy dan error embedding menjadi `null`. Uji fallback keyword tanpa model dan tes embedding opsional terpisah. Jangan menganggap chat berhasil membuktikan ONNX sudah berjalan.
- `.github/workflows/ci.yml`: saat ini hanya Ubuntu. Usulan matrix Ubuntu + Windows dengan Node 24 dan pnpm pinned; jalankan typecheck/test/lint dan smoke foreground. Noir/Vibe Guard bukan lagi prasyarat CI sesuai pencabutan pengguna.
- `.github/workflows/build.yml`: ada target Windows pada pipeline manual lama berbasis pkg, tetapi komentar menyebutnya superseded. Ini bukan bukti rilis Windows terkini berhasil.
- `.github/workflows/release.yml`: rilis utama Bun hanya macOS ARM64. Tambahkan target Windows dan installer PowerShell setelah jalur Node lulus, uji addon native serta TUI dynamic import dalam binary, verifikasi checksum dengan `Get-FileHash`, dan smoke-test pada Windows tanpa Node. Tidak menerbitkan binary sebelum seluruhnya tervalidasi.

## Urutan implementasi

1. Jalankan pilot foreground dan catat kegagalan nyata; perbaiki hanya blocker yang terkonfirmasi.
2. Terapkan CLI portabel, pemilihan plugin, serta kasus path/editor.
3. Selesaikan readiness + shutdown + background, kemudian autostart.
4. Validasi voice/Claude/embedding sebagai fitur opsional.
5. Tambahkan CI Windows dan packaging release setelah flow pengguna lulus.
